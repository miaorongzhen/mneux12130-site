可以继续试什么？

这个页面适合做前端设计、交互组件、作品入口和公开演示。凡是能在浏览器里运行的静态内容，都可以逐步放上来。

01 / UI

视觉系统

练习配色、排版、响应式布局和页面气质，让域名从测试页变成一个可展示的入口。

02 / JS

交互组件

添加按钮、切换状态、表单、计数器、模拟器或小工具，全部在前端运行。

03 / LAB

部署实验

测试 GitHub Pages、DNS、HTTPS、缓存刷新和以后可能接入的前端框架。

小控制台

这个交互不需要后端。点击按钮会改变页面状态，用来确认 JavaScript 已经在浏览器里运行。

切换实验模式
